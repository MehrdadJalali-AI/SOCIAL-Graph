\section*{Data and code availability}
\label{sec:availability}
All code, configurations, pinned data versions with checksums, per-run evaluation logs (summaries), statistical outputs, figures and the deviation log are available at \url{https://github.com/MehrdadJalali-AI/SOCIAL-Graph}. QMOF v18 is available from Figshare (DOI 10.6084/m9.figshare.13147324), and the original MOFGalaxyNet data from \url{https://github.com/MehrdadJalali-KIT/MOFGalaxyNet}. Running \texttt{python -m graphsocial.run --stage all --force} reproduces every number in this paper; a smoke configuration finishes in a few minutes.
