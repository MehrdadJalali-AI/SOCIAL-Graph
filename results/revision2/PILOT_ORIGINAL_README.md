# Original pilot (before the influence-shift correction)

These files are copies of the stage 6 pilot outputs exactly as they were before the correction (deviation D22). They were taken from `results/tables/phase6_wilcoxon.csv` and `phase6_pilot.csv` at commit `c2177bf^`, the commit before `c2177bf`.

The topology selection (ρ = 0.10) was made on these values. All other results use the corrected implementation.

| File | Contents |
|---|---|
| `pilot_original_wilcoxon.csv` | Original pilot tests. |
| `pilot_original_runs.csv` | Original per-run pilot results. |
| `pilot_original_vs_corrected.csv` | Mean, standard deviation and total hits per variant, original vs corrected. |
