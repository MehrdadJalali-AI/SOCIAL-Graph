1. Jalali, M.; Vu, B.; Chandna, S.; Nadimi-Shahraki, M. H. SOCIAL: Social network optimization algorithm via centrality and influence-aware learning. *Applied Soft Computing* **2026**, *194*, 114914. https://doi.org/10.1016/j.asoc.2026.114914

2. Jalali, M.; Wonanke, A. D. D.; Wöll, C. MOFGalaxyNet: a social network analysis for predicting guest accessibility in metal–organic frameworks utilizing graph convolutional networks. *Journal of Cheminformatics* **2023**, *15*, 94. https://doi.org/10.1186/s13321-023-00764-2

`MOFGalaxyNet_JCheminf_2023.pdf` in this folder is the publisher's open-access version (CC BY 4.0) of reference 2.
